# 🎥 YouTube Video Search Using Hadoop & Apache Spark

A data engineering project that retrieves YouTube video information through the YouTube Data API and leverages Big Data technologies to process and handle video-related data.

The project combines API integration with distributed data processing using **Hadoop** and **Apache Spark**, demonstrating how Big Data tools can be applied to real-world data retrieval and processing tasks.

## 🚀 Tech Stack

- **Python** – Application logic and API integration.
- **YouTube Data API** – Fetching video information through search endpoints.
- **Apache Hadoop** – Distributed storage and Big Data infrastructure.
- **Apache Spark** – Distributed data processing and analysis.

## ✨ Key Features

- Fetch YouTube videos using API search endpoints.
- Retrieve video-related information from YouTube.
- Process retrieved data using Apache Spark.
- Utilize Hadoop as part of the Big Data processing environment.
- Handle data processing workflows using distributed computing technologies.

## 🏗️ Project Architecture

The project follows a data processing workflow:

1. **Data Retrieval:** Send requests to the YouTube Data API.
2. **Data Collection:** Retrieve video information from search results.
3. **Data Processing:** Process the collected data using Apache Spark.
4. **Big Data Infrastructure:** Integrate with Hadoop for distributed data handling.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Python
- Apache Hadoop
- Apache Spark
- Java
- YouTube Data API Key

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Sama-Zain10/YouTube-Video-Search-Hadoop-Spark.git

cd YouTube-Video-Search-Hadoop-Spark
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Configure API Credentials**

Create a `.env` file and add your YouTube API key:

```env
YOUTUBE_API_KEY=your_api_key
```

**4. Run the application**

Run the project using its configured entry point and make sure Hadoop and Spark services are properly configured.
